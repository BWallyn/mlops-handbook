# Structure your repo

## Your assignment

Now that you have learned how to structure your repository, develop robust code and format the architecture, it is time to apply to your own project. The goal is to adapt the repo of your project to the Kedro framework.


## What to do to update your repository

Your job is now to update the repo of your project to use Kedro.

What should you do?
1. Create a new repo using `kedro new`. Choose the name of the github repo already created. For the options, we advise you to select 1) Lint, 2) Test and 5) Data Folder.
2. Merge this new Kedro repo into your old repo. To do so:
   1. Copy the git / github files into this new kedro folder.
   2. Move your data to the right data/ folder of Kedro.
   3. Move your notebooks to the notebooks/ folder.
3. Create your environment:
   1. Create a new python environment with venv or uv.
   2. Install the dependencies using uv.
   3. Add the dependencies you know you will need using uv.
4. Adapt your process to the Kedro framework:
   1. Create a new pipeline for each part of your project, based on your architecture.
   2. Move the functions to the nodes.py files.
   3. Create the pipelines in the pipeline.py files to order the call of your functions.
   4. Put the parameters of the functions in the parameters_<pipeline_name>.yml files.
   5. Add the data you want to store in your catalog.yml file.

You want to do it step by step, one pipeline at a time in order to ease the process of moving your repository to the Kedro framework.
