# Validate your project

## Your assignment

Now that you have learned how to validate your parameters and data, now it's your time to use it for your project! The goal is to validate the parameters you use in your functions by defining them in a conf files.


### Feature engineering and validate parameters

After learning these validation methods, now could be a good time to work on your feature engineering process. Your feature engineering process will depend on your dataset and the model you want to use to solve your problem. You can check [scikit-learn](https://scikit-learn.org/stable/) or their new package [skrub](https://skrub-data.org/stable/) to create your pipeline. The important part here is to create functions with parameters that you will load from a conf file (*parameters_feature_engineering.yml* for example) and you will validate using a **pydantic** class.

What should you do?
1. Develop feature engineering functions adapted to your dataset and the model you want to use.
2. List all the parameters of all the functions you developped and store them in a conf file, *parameters_feature_engineering.yml* for example.
3. Create a **pydantic** class to validate all your parameters and implement it at the beginning of your fearture engineering process. You prefer to crash the process at the beginning instead of after several minutes (or hours) because of a function parameter type not expected.
4. Load the parameters from your conf file and run your whole feature engineering pipeline process.


### Validate your dataset before training your model

Once you have developed your feature engineering pipeline, the next step is to validate the dataset before training your model in order to avoid strange model predictions because of the dataset. Therefore, define a **pandera** schema to validate the data you will use in your model.

What should you do?
1. List all the features you want to use to train your model.
2. Create a **pandera** dataframe schema to validate the features used to train the model.
3. Implement the function to validate the dataframe at the end of the feature engineering pipeline, before training your model.
